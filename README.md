# E-commerce Sales Performance Analysis
# "This project uses SQL and Power BI as its tools." 

A beginner portfolio project using SQLite and Power BI
to analyze e-commerce sales performance.

## Business Questions

1. How much revenue did completed orders generate?
2. How did revenue change by month?
3. Which product categories generated the most revenue?
4. Which customer regions generated the most revenue?
5. What proportion of orders were completed, cancelled, or returned?

## Tools

- SQLite
- SQL
- Power BI

## Dataset

This project uses synthetic data created for portfolio practice.

- Customers: 50 records
- Products: 20 records
- Orders: 500 records
- Analysis period: 2024–2025

Revenue and average order value include completed orders only.
Region refers to the customer's region, not the shipping location.

## Key Findings

- Completed-order revenue: 2,736,413.66.
- Completed orders: 428.
- Average order value: 6,393.49.
- Monthly revenue peaked in July 2025 at 205,381.45.
- Electronics generated the highest category revenue at 1,119,271.92.
- Bangkok generated the highest regional revenue at 843,657.88.
- Completed orders accounted for 85.6% of all orders.

## Project Files

- SQL analysis: `sql/sales_performance_analysis.sql`
- Power BI report: `powerbi/ecommerce_sales_performance_dashboard.pbix`
- Source data: `data/`

## Limitations

- The dataset is synthetic and does not represent a real business.
- The analysis describes observed patterns, not their causes.
- The dataset does not include profit or marketing costs.
